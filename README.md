# Curso de Python — Curso em Vídeo

Repositório de estudos e exercícios do curso de Python da plataforma **[Curso em Vídeo](https://www.cursoemvideo.com/)**, do professor Gustavo Guanabara.

## O que tem aqui?

- **`exercicios_py/`** — Resolução dos 100 exercícios propostos ao longo do curso, organizados em pastas com grupos de 10 exercícios (`exer 01-10`, `exer 11-20`, ..., `exer 91-100`). Cada arquivo segue a numeração do enunciado (`ex001.py` a `ex100.py`).
- **`aulas/`** — Anotações e exemplos de código feitos durante as aulas (listas, dicionários, funções, etc.), correspondentes às aulas 17 a 20 do "Mundo 3" do curso.
- **`assets/`** — Arquivos de mídia usados em alguns exercícios e testes.

## Estrutura do curso

O curso do Curso em Vídeo é dividido em três "Mundos":

1. **Mundo 1** — Fundamentos: tipos primitivos, operadores, módulos, cores no terminal.
2. **Mundo 2** — Estruturas de controle: condicionais (`if`/`else`) e laços (`for`/`while`).
3. **Mundo 3** — Estruturas de dados e funções: tuplas, listas, dicionários, funções, módulos e pacotes.

## Como executar

Com o Python 3 instalado, basta rodar qualquer exercício pelo terminal:

```bash
python exercicios_py/exer\ 01-10/ex001.py
```

## Observações

Este repositório é um material pessoal de estudo, com as minhas próprias resoluções e anotações. Os enunciados dos exercícios pertencem ao Curso em Vídeo.
